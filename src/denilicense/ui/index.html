Integration guide

Designing entitlements

Entitlements are signed license claims that your software reads after it validates the license or activation lease. Use stable names and deny access when a key is absent, malformed, or false.

Choose a value by behavior

Boolean
Turn a feature on or off: "feature.analytics": true
Integer
Set a count or quota: "limits.projects": 25
String
Select a named tier or mode: "plan": "professional"

Example

{
  "feature.analytics": true,
  "feature.export.pdf": false,
  "limits.projects": 25,
  "plan": "professional"
}

Fail closedValidate the signed license first. For every entitlement, enforce the expected type and a safe range. Treat missing, unknown, or invalid values as disabled; never trust client-edited JSON.

Open the complete entitlement integration and rollout guide for Python examples, caching rules, migrations, tests, and security guidance.
